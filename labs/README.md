# Laboratorios

| Semana | Contenido |
|---|---|
| **1** | **Entorno de desarrollo y primer programa.** VS Code, compilador portátil, estructura mínima de un archivo `.cpp`, compilar con `g++`, ejecutar, `cout`, errores básicos de compilación. |
| **2** | **Variables, entrada/salida y expresiones.** `int`, `double`, asignación, `cin`, `cout`, `+ - * / %`, expresiones sencillas, entrada → procesamiento → salida. |
| **3** | **Condicionales.** Operadores relacionales y lógicos. `if`, `if-else`, `else if`, condiciones anidadas y compuestas. Casos límite. |
| **4** | **Evaluación 1 + introducción a ciclos.** Evaluación sobre Labs 1–3. Después: concepto de repetición, `while` y comparación intuitiva con repetir instrucciones manualmente. |
| **5** | **Estructuras repetitivas.** `while`, `do-while`, `for`. Ciclos controlados por contador y condición. Errores comunes: ciclos infinitos y off-by-one. |
| **6** | **Procesamiento con ciclos y organización del programa.** Contadores, acumuladores, máximos/mínimos, promedios, validación. `switch`, menús. Introducción mínima a funciones propias. |
| **7** | **Evaluación 2 + introducción a arreglos.** Evaluación sobre ciclos, condicionales, acumuladores, menús y funciones básicas. Después: necesidad de almacenar múltiples valores, declaración y acceso a arreglos. |
| **8** | **Arreglos y procesamiento de colecciones.** Declaración, inicialización, índices, recorrido con `for`, lectura/escritura, suma, promedio, máximo, mínimo, conteos y búsqueda. Funciones que reciben arreglos. (Nota: asignar evaluación 3) | 
| **9** | **Procesamiento de datos y cadenas.** `string`, recorrido y operaciones básicas con texto. Ejercicios que combinen arreglos, strings, búsquedas, estadísticas y funciones. |
| **10** | **Evaluación 3 + estructuras (`struct`).** Entrega/validación breve del proyecto de arreglos. Luego: definición de `struct`, miembros, creación de registros, arreglos de estructuras y búsqueda de registros. |
| **11** | **Punteros.** Dirección de memoria, `&`, declaración de punteros, `*`, desreferenciación, punteros a variables. Relación básica arreglo–puntero. Punteros a estructuras y operador `->`. |
| **12** | **Evaluación 4 / Proyecto final.** Integración de funciones, arreglos, `struct`, punteros y estructuras de control. Demostración, revisión del código y breve defensa por pareja. **Sin contenido nuevo.** |
